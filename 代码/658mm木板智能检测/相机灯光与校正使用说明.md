# 658mm 相机灯光与校正（2026.09.23）

本版在上位机内接入厂家 CLConfigurator 2026.07.25 的64位SDK，主界面新增“相机灯光与校正”页。
独立板缝识别、四种木皮分级、四种采图模式及 TCP JSON 接口继续保留。311mm旧相机程序没有更换SDK。

## 连接并核对参数

1. 完整解压新版；现场电脑仍需安装 IKap 采集卡驱动及厂家64位VC++运行库。
2. 关闭厂家 CLConfigurator 和 IKapExpert，避免设备或控制口被占用。
3. 在“设备与自动采图”中沿用现场调通的 `.vlcf`，连接采集相机。
4. 停止自动采图，等待图片保存和PLC确认命令结束。
5. 打开“相机灯光与校正”，点击“搜索端口”，选择相机的控制端口，再点“连接并读取”。
6. 右侧表格显示相机回读值和回读时间。连接操作不写入灯光、增益、触发或校正参数。

控制口可能来自Camera Link采集卡，也可能显示Windows COM口；不要选择PLC的RS485口。
控制口和采集卡必须对应同一台相机。软件拒绝与已配置PLC COM口相同的控制口，但不能自动识别现场接线。
若没有找到端口，先检查厂家配置软件能否找到相机及对应驱动。自动采图期间暂停校正接口操作，表格保留上次读数。
PLC无需连接即可使用本页；生产自动采图仍按原流程连接PLC。

## 灯光与预览

- RGB灯光分别调节；量程按厂家回读的标志处理，不套用示例值5。增益范围1～20，响应偏移0～255。
- 校正算法0为Basic均值，1～255为Vendor定值，按厂家现场要求选择。
- “应用”先检查支持的参数，再写入并回读比较。部分写入或回读不一致时显示失败和实际值，经过记入校正记录。
- “启动校正预览”显示最近最多1024行的图像条带，保留采集宽度；显示时缩放，保存PNG时保留原像素。
- RGB均值和各通道大于等于254的像素比例仅供亮度检查，不能代替标准色卡的颜色精度验证。
- “保存预览原像素PNG”存到 `data/camera_calibration`，不占生产编号，不加入板缝/分级/TCP生产任务。

预览不做额外白平衡、Gamma或颜色增强。PNG可与厂家软件同条件保存的原图对比。
SDK接入本身不保证消除色差。调好后，应使用有人工等级标签的样板复核颜色分级结果。

## 明暗场校正步骤

1. 确认控制口与采集卡属于同一相机，启动校正预览，等待收到图像。
2. 按厂家要求设置校正算法、增益等；点击“停用平场校正”，确认回读为0。
3. 点击“关RGB并记住当前值”，遮挡外界光；勾选暗场条件已准备好，点击“生成暗场校正”。
4. 保持采图并按厂家要求等待暗场过程稳定，再点“恢复关灯前RGB”。
5. 放置覆盖扫描区域的均匀白色目标，按厂家示例要求动态采集；勾选亮场条件已准备好，点击“生成亮场校正”。
6. 保持采图并按厂家要求等待亮场过程稳定，再点“启用平场校正”，核对回读为1并检查图像。
7. 选择用户配置集0～8，点击“保存该用户集并设为默认”；会覆盖所选用户集。
8. 停止校正预览、断开设备。在现场允许时相机断电重启，再连接并回读，与保存前导出记录比较RGB、增益、偏移、FFC和默认用户集。

厂家SDK头文件没有提供校正进度或完成回调，程序显示“命令已应答”，不会标为“校正完成”。
保存命令的成功应答也不等于断电保持已验证，需要现场执行上述核验。
相机未回读的字段保持未知/不允许写入，不用软件默认值冒充实际值。

预览沿用 `.vlcf` 的行触发/编码器配置，不自动修改为自由运行；无图像时请核对行触发条件。
预览与生产采图互锁，最多持续5分钟，可停止后重新启动。预览内存有界，不受生产单板总字节上限影响；停止后恢复生产单板限制。
断开控制口不会擅自恢复灯光或关闭校正，相机保留最后写入状态。暗场后请按流程恢复灯光。

## 记录与源码

“导出相机参数”保存厂家原始文本、SDK解析值、控制口和读取时间。
每次写入保存请求、各步应答、之后回读和错误。点“打开校正记录目录”查看 `data/camera_calibration`。
这里的JSON是诊断记录，不是可导入相机的校正系数文件。

- `boardcapture/cl_config.py`：SDK、参数回读、操作记录。
- `boardcapture/cl_config_gui.py`：新页面。
- `boardcapture/cl_preview.py`：预览和PNG。
- `native/cl_config_bridge.cpp`：C++接口到Python桥接，不使用pythonnet。
- `native/include/lsn_cl_conf.h`、`native/lib/lsn_cl_configurator.lib`、`camera_driver/lsn_cl_configurator.dll`：厂家原始文件。
- `native/ikap_bridge.cpp`：专用预览入口。

PyCharm解释器沿用 `D:\项目\板缝识别\软件\venv\Scripts\python.exe`，运行 `main.py`。
重编译桥接先执行 `native/build_cl_config.cmd`、`native/build.cmd`，再执行 `build.ps1` 打包。
本机软件测试使用模拟相机和替身SDK；没有连接现场658相机，未做真实校正或色差精度验收。
