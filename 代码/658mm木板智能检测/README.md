# 658mm木板智能检测

2026.09.23 相机校正版：增加CLConfigurator SDK、相机参数回读、RGB灯光、明暗场校正与专用预览。保留独立手动分级窗口、四种采图模式、TCP JSON结果接口。

新增功能见“相机灯光与校正使用说明.md”。相机控制口由用户选择，连接时不写入参数。

开发入口：main.py。PyCharm 解释器：<仓库目录>\软件\venv\Scripts\python.exe。
分级主要代码：boardcapture/grading.py、grading_gui.py；界面入口：boardcapture/gui.py。
运行 build.ps1 打包，产物在“软件/待发布”，不覆盖使用中的程序和现场数据。
分级权重已导出 ONNX，放在 models/grading，运行无需安装 PyTorch 或联网下载模型。
export_grading.py 可从用户的四套 best.pt 重新导出并比对结果。
已增加相机校正SDK和预览入口；PLC、生产触发、存图与识别算法保留。

木皮选择：红橡（浅色/深色）；欧橡（浅色/深色/双色/中色）；色木（ABCD类/E类）；山核桃（白色/浅色/深色/中色）。
选择种类后导入同一种木皮图片，再点击开始分级。不同种类分批处理；程序不自动判断材种。
按训练代码对整张图转RGB、Pillow双线性缩放到224×224，再用ImageNet均值标准差归一化。
颜色分级结果不代表尺寸/缺陷综合等级；色木不能进一步拆分A、B、C、D。
已完成结果写入独立结果目录的items/*.json和分级汇总.csv，原图不移动、不修改。
暂停与退出后使用“打开/继续已有任务”选择request.json恢复；失败图片可在修复后重试。
关闭手动分级窗口只隐藏；退出整个软件会暂停手动批次。
主界面上方可选择只采图、采图＋板缝、采图＋分级或两者均启用，点击应用模式后生效。
自动任务在完整板图保存后排队，与后续采图并行；材种由操作员选择。
在线结果与TCP在“采图联动与实时输出”页设置，详见TCP接口说明.md。
退出时未完成的在线任务保留为待继续，恢复结果标记为历史板图。

验证：四个模型与原始权重对8张现有例图共32次输出比对、单元/GUI测试、模拟采图与分级并行测试。
例图没有分级真值标签，以上是程序一致性验证，不是现场分级准确率报告。
